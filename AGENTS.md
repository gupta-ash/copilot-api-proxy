# Engineering

Read README.md and docs/{architecture,design,implementation}.md before changing this component. Use docs/testing.md and docs/deployment.md for validation/release boundaries. Author in an authorized non-live source checkout/worktree; never patch installed services or use release extraction as a development checkout.

Preserve runtime/npm/bin identity `copilot-proxy`, protocol routes, transformation policy, authentication/private APP_DIR semantics, source tests, frozen lock and legal attribution. Source deploy/ operators export to installed scripts/ paths; their one-level parent-root derivation is intentional. The public repository/download identity is gupta-ash/copilot-api-proxy.

A source task does not authorize publishing, installing dependencies, accessing credentials, changing autostart, enabling hooks, restarting a shared service or contacting another host. The saved root install.ps1 is a local current-user install/update command: latest stable by default, optional exact Version/Check/Verify/WorkRoot, automatic actual OS profile and existing Node discovery. No Python, fleet/staging/source checkout or runtime provisioning is required. Retain complete source/member admission, one-hop verified frontdoor updates without self-overwrite, exact-byte adoption and independent installed verification before success.

Proxy activation always needs exact interactive consent against component/version/PID/root/live peers. Ordinary running-code updates may offer that existing prompt; decline/noninteractive input refuses before writes. No stopped-service auto-start. Preserve existing registrar variants and latest private state. No automatic code/database rollback after activation failure, stale state restoration or mass port-based kill.

Public fixtures must be synthetic protocol cases, not regex-redacted private conversations. Preserve upstream copyright/license notices, and keep auth tokens, captures, traces, histories, environments and real state out of source/releases.
